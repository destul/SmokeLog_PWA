# Нікотин — облік

Особистий офлайн-лічильник сигарет, стіків IQOS, затяжок вейпа та снюсу. Дані
зберігаються лише у браузері пристрою, без акаунта, сервера чи аналітики.

## Запуск локально

```bash
cd web
npm install
npm run dev -- --host 0.0.0.0
```

Перевірка і production-збірка:

```bash
npm run test
npm run build
npm run lint
npm run preview -- --host 0.0.0.0
```

## Дані й приватність

- Пачка сигарет, стіків і снюсу має ціну та кількість — вартість рахується за
  одну одиницю.
- Для вейпа зберігаються затяжки; у версії 0.1 їхня вартість не рахується.
- Сьогоднішній лічильник автоматично починається заново після місцевої півночі;
  історія в журналі залишається.
- Очищення даних сайту у браузері також очищає журнал.

## Публікація

Проєкт збирається для GitHub Pages за адресою `/SmokeLog_PWA/`. Workflow у
`.github/workflows/deploy-pages.yml` встановлює залежності, збирає `web/dist`
та публікує його як статичний HTTPS-сайт. PWA стає доступною офлайн після
першого успішного відкриття.

Якщо пізніше з'явиться синхронізація, її треба розгортати окремим сервісом від
AirMap і залишити локальний офлайн-режим придатним без неї.
