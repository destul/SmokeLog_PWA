# SmokeLog 0.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship SmokeLog 0.4 analytics, languages, reduction support, achievements, and clear observed-versus-projected reporting.

**Architecture:** Keep calculations pure in `web/src/domain`, persist only language and daily-goal preferences in the existing settings store, and render the features in the existing Today/Week/Settings layout. Do not introduce a server, account, migration, or backup-format change.

**Tech Stack:** React 19, TypeScript, Vite PWA, Vitest, Testing Library, IndexedDB via idb.

**Spec:** `docs/superpowers/specs/2026-08-26-smokelog-0.4-design.md`

## Global Constraints

- Exclude VPS, domain, HTTPS, accounts, and synchronization from 0.4.
- Preserve existing event/product IDs, IndexedDB data, and JSON backup compatibility.
- Use local calendar days and existing product-price calculations.
- Supported languages are Ukrainian, Russian, and English; Ukrainian remains the default.
- Forecast values are explicitly labeled projections and never presented as observed spending.
- Keep the existing 0.3.1 product action menu and journal behavior intact.
